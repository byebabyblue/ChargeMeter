# 充电信息 ChargeMeter

一款面向 Android / ColorOS 的本地电池监测应用，用于查看实时充放电功率、充电曲线、电量和温度历史、充电记录以及应用使用期间的耗电情况。

## 主要功能

- 实时功率、电流、电压、电量与电池温度
- 独立保存每次充电，支持功率、电量和温度交互曲线
- 自动生成两次充电之间的使用记录
- 统计区间亮屏时长、前台应用功率及使用时温度范围
- 使用 AccuBattery 2.0 的样本门槛：单次充入至少 60%，收满最近 5 次有效充电后显示健康度
- 双电芯电流或电压换算、功率量程和标称容量设置
- 前台服务通知与 ColorOS 后台记录支持

## 健康度计算

小于 60% 的充电记录仍会保留，但不进入健康度。只有已结束、测量数据足够且采样缺口不超过 2 分钟的记录才可成为有效样本。应用只选最近 5 次有效充电，将实际充入的总 mAh 除以这些记录的总电量增幅，推算满充容量，再与设置中的厂商标称容量比较。收集不足 5 次时不显示健康度数值。

设置中的“增强后台记录”默认关闭，开启后会使用 CPU 唤醒锁减少息屏休眠造成的采样中断，增加待机耗电。此模式需要开启实时通知、允许后台活动并忽略电池优化，仍不能保证抵抗系统强行停止。

## 构建

项目使用 Kotlin、Jetpack Compose 和 Room，要求 JDK 21 与 Android SDK。

```bash
./gradlew assembleDebug
```

APK 输出位置：`app/build/outputs/apk/debug/app-debug.apk`。

## 权限说明

- 通知权限：显示持续监测通知
- 使用情况访问权限：统计前台应用时长
- 忽略电池优化：提高后台记录连续性

所有电池历史默认保存在设备本地。
